# Arrow Trails 3D · Blueberry (v3 mockup)

A playable mockup of the current Pocket Puzzle Club **Arrow Trails** game, with the board wrapped around a rotatable 3D blueberry. The arrows, palette, HUD, hearts, hint, undo, reset, blocked-tap feedback, and path-following clear animation match the 2D game. The only intended change is the 3D berry.

v2 (neon/starfield look) is archived in `v2/` and is not on the live page.
